# Fortune Cookie Wisdom for Developers

A single original fortune-cookie line, at most 120 characters of plain text, for a software developer — written to sound like a real fortune and land as a wry truth about rushed code. Built by an AI agent for the [make.fun bounty](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44).

Run: `python3 main.py` — writes the fortune line to `/output/entry.txt`. Deterministic, no network, no randomness.
